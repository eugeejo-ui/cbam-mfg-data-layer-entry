## 4. 코드별 처리 내용

**01_collect_dart.py (수집)**
1. 전체 회사 코드 중 종목코드 보유 회사(상장사) 추출
2. 회사별 기업개황 수집, 제조업(업종코드 중분류 10~34) 및 유가증권·코스닥만 추출
3. 2025년 사업보고서 주요계정 수집. 당기·전기·전전기(2025·2024·2023) 3개년이 한 보고서에 포함됨
4. 2025년 보고서 미제출 기업은 2024년 보고서로 재시도
5. 중단 시 재실행하면 수집 완료분은 건너뛰고 이어서 진행

**01b_check_step1.py (점검)**
- 시장 구분 분포, 빈 값 수, 대표 기업 단위 확인, 3개년 확보 여부 점검

**01c_diagnose_revenue.py (진단)**
- 보고서는 있으나 별도 매출이 빈 기업의 수집 항목 목록 출력

**01d_patch_revenue.py (보완)**
- 매출 누락 기업만 전체 재무제표 API로 재수집
- 2025년 보고서에서 2025·2024년, 2024년 보고서에서 2023년 매출 확보
- 실행 전 원본 자동 백업, 값의 출처를 rev_source 열에 기록 (주요계정 / 전체재무제표)

## 7. 판정 기준 (2단계 사용)

**대기업**
- 공정위 상호출자제한기업집단 소속 (2026년: 자산 12조 원 이상, 47개 집단)
- 법인등록번호로 공정위 명단과 대조

**중소기업**
- 최근 3년 평균 매출이 업종 기준 이하 (시행령 별표 1, 2025-10-01 개정)

| 기준 | 제조업 |
|---|---|
| 1,800억 원 | C17 종이, C24 1차 금속, C28 전기장비 |
| 1,500억 원 | C14 의복, C15 가죽·신발, C32 가구 |
| 1,200억 원 | C10 식료품, C20 화학, C22 고무·플라스틱, C25 금속가공, C29 기계장비, C30 자동차, C31 기타 운송장비 |
| 1,000억 원 | C12 담배, C13 섬유, C16 목재, C19 석유정제, C26 전자부품·통신, C33 기타 제품 |
| 800억 원 | C11 음료, C18 인쇄, C21 의약품, C23 비금속 광물, C27 의료·정밀기기 |
| 600억 원 | C34 산업용 기계 수리 |

- 예외: 자동차용 의자(C30393) 등 일부 세부 업종은 1,500억 원
- 매출 기준 이하여도 자산총액 5,000억 원 이상이면 중소기업에서 제외

**중견기업**
- 대기업·중소기업 어디에도 해당하지 않는 기업

**보조 규칙**
- 별도 매출이 없고 연결 매출이 있는 경우(지주회사형) 연결 매출로 대체 판정
