## 1. 요약
- CBAM 적용 시점이 가장 이른 중견 기업군의 IT 예산 규모가 가장 작음
- IBM 온라인 버전 최소 구성 도입 시 1차 적용 대상 중견 기업의 IT 예산 증가율은 3.0% 수준임
- 상시 운영 구성 시 1차 적용 대상 중견 기업 중앙값 11.9%, 상위 25% 기업은 28.9% 이상 증가 필요
- 대기업은 동일 조건에서 0.2~0.8%로 부담 수준이 낮음
- 진입 경로는 소규모·사용량 기반 구성이 필요하며, 설치형은 연 1억 원대 수준이 기준선임

## 4. 계산 방식

**IT 예산 (분모)**
- 한국인터넷진흥원 정보보호 공시의 정보기술부문 투자액을 실측 IT 예산으로 사용
- 포함 항목: IT 자산 감가상각비, IT 인건비, 시스템 구입·유지보수, IT 서비스 이용료, 외주·컨설팅, 교육, 통신비
- 2025년 실적 우선 적용, 2026년 공시 미포함 기업은 2024년 실적과 2024년 매출로 대체
- 공시값이 없는 기업은 계산에서 제외 (비율 추정 미사용)

**A 비용 (분자)**
- 연간 비용 = (엔진 RU/시간 × 가동 시간 + 기본 지원 3 RU/시간 × 과금 시간) × 1달러 × 환율
- 엔진: Presto Starter 2.00 / Small 11.20 / Medium 19.60 RU/시간
- 가동 시간: 업무시간(연 2,640시간) / 24시간(연 8,760시간)
- 기본 지원비: 엔진 정지 시 과금 여부가 공식 문서에서 확인되지 않아 두 경우 모두 계산
- 정가 기준, 저장소 비용 제외

**핵심 지표: IT 예산 증가율**
- IT 예산 증가율 = A 연간 비용 ÷ 정보기술부문 투자액
- CBAM 대응 시스템은 규제 대응 목적의 필수 지출로, Gartner 분류상 유지(Run)에 해당함
  - Gartner 기준: 차별화되지 않은 필수 업무를 지원하고 직접 수익을 창출하지 않는 지출은 유지(Run)로 분류
- 필수 지출은 기존 예산 전용보다 IT 예산 증액으로 충당된다고 보고, "IT 예산의 증가 폭"으로 해석함
- 별도 비율 가정이 필요 없는 지표임

**참고 비교: 신규 프로젝트 예산 대비**
- 기업이 신규 프로젝트로 분류할 경우를 가정한 참고용 지표
- 신규 프로젝트 비중 15% (Deloitte 2020), 21% (Deloitte 2023 transform)

**B·C·D 기준선 (가격 비공개)**
- IT 예산 1%에 해당하는 금액: 가격 공개 시 IT 예산 증가율로 환산하기 위한 기준값
- 신규 프로젝트 예산 전액(15%, 21%): 가장 관대한 가정의 상한선
- C는 상한선을 필요 VPC 수(워커 1대분 20 VPC)로 나누어 VPC당 연간 허용 단가 산출

## 7. 주요 발견
- 대기업과 중견 기업의 정보기술부문 투자액 중앙값 차이는 약 7배 (204.5억 원 vs 28.6억 원)
- 대기업은 온라인 버전 중형·24시간 구성 시에도 IT 예산 증가율 0.8%로 부담 수준이 낮음
- CBAM 적용 시점이 이른 중견 기업일수록 정보기술부문 투자액이 작음 (1차 적용 대상 14.3억, 2차 적용 예정 대상 17.6억, 비대상 33.3억)
- 1차 적용 대상 중견 기업
  - 최소 구성 도입 시 IT 예산 증가율 3.0%
  - 중형·24시간 구성 시 11.9%, 상위 25% 기업은 28.9% 이상
- 설치형·BYOC·기존 기반 추가는 가격 비공개로 판정 불가. 1차 적용 대상 중견 기업 중앙값 기준 IT 예산 1% = 연 1,433만 원, 신규 프로젝트 예산 전액 기준 상한 연 2.15억~3.01억 원
- 시사점: 적용 시점이 이른 기업일수록 IT 예산이 작으므로, 진입 경로는 소규모·사용량 기반 구성이 필요함

## 9. 한계
- IBM 정가 기준이며 실제 계약 할인은 미반영
- 정보기술부문 투자액은 감가상각비 기준이므로 일반적인 IT 예산보다 작게 집계될 수 있음 (증가율이 높게 산출될 가능성)
- A 비용은 사용량 가정에 따라 연 1,803만~2억 7,044만 원으로 변동함. 기업별 실제 사용량은 확인 불가
- A는 공개 자료상 서울 리전이 없어 국내 보관이 필요한 기업에는 가격과 별개로 적용이 어려울 수 있음
- 기본 지원비의 엔진 정지 시 과금 여부 미확인
- 저장소(오브젝트 스토리지) 비용 제외
- B·C·D는 가격 비공개로 진입 가능 여부를 판정하지 않고 기준선만 제시함
- 1차 적용 대상 공시값 확보 27곳, 2차 적용 예정 대상 20곳으로 표본 규모가 작음
- 공시값이 없는 중견 기업 349곳(주로 매출 3,000억 원 미만)은 측정 제외. 해당 구간의 부담이 더 클 가능성 있음
- Deloitte 조사 응답 기업은 IT 투자 비중이 높은 기업이므로 신규 프로젝트 비중을 국내 중견 제조기업에 그대로 적용하기 어려움
- 공시 파일과 상장사 목록은 회사명으로 대조함 (법인등록번호 미제공)
