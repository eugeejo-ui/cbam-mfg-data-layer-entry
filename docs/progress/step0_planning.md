- 중견 제조기업 중 현재 IBM 데이터 층 진입이 가능한 기업과 불가능한 기업을 구분함
- 2027~2028년 EU CBAM 적용 단계에 따라 데이터 대응이 필요한 기업군과 시점을 제시함

## 3. 핵심 가설 (계산 결과에 따라 수정)

1. **수요 성격 전환**
   - 데이터 관리 동기가 "AI 도입 준비"(선택 과제)에서 "규제 대응"(의무 과제)으로 전환됨
2. **두 단계 적용**
   - 1차 적용: 철강·알루미늄·시멘트·비료 원재료. 2026년 수입분 첫 신고 기한 2027-09-30
   - 2차 적용 예정: 자동차 부품·가전·건설자재·변압기·케이블·산업장비 등 180개 하류 제품. 2028-01-01 적용 예정 (확정 전)
3. **두 단계의 데이터 연결**
   - 2차 적용 예정 대상 기업의 신고 배출량에 1차 적용 대상 기업의 검증 배출 데이터가 포함됨
4. **IBM 데이터 제품의 위치**
   - CBAM 계산 도구 영역은 전용 소프트웨어 또는 IBM Envizi(Automation 소속 추정)가 담당함
   - IBM Data & AI 데이터 제품(데이터 통합, watsonx.data, 데이터 인텔리전스)은 하단에서 데이터 수집·저장·추적을 담당함
   - 2차 적용 예정 대상 기업의 도구 선정 시점이 2027년으로 예상되므로, 대응 준비 시점도 2027년으로 판단함

## 4. 방향 결정 기록

| 순서 | 검토 사항 | 결정 | 근거 |
|---|---|---|---|
| 1 | GPU 비용 곡선 vs watsonx.data 진입 비용 | watsonx.data 채택 | GPU 모델 배포 비용은 선행 프로젝트와 중복됨. 데이터 층이 IBM 판매 제품과 직접 연결됨 |
| 2 | 서울 리전 부재를 결론으로 사용 | 결론에서 제외, 계산 조건으로만 사용 | 본사 결정 사안으로 국내 조직 차원의 과제가 되기 어려움. 공개 자료 한계로 오판 위험 있음 |
| 3 | 고객별 견적 지도 작성 | 지도는 도구로만 사용, 결론은 시간에 따른 변화로 설정 | IBM 내부에 실제 단가 기반 견적 도구가 이미 존재할 가능성 높음 |
| 4 | 대상 기업 규모 | 중소기업 제외, 중견 기업 중심 | 중소기업은 투자 예산 규모가 설치형 도입 단위와 불일치함. 중견 기업은 데이터 공백이 크고 계산으로 확인할 구간임 |
| 5 | 국가핵심기술 보유 여부 | 분석 축에서 제외 | 보유기업 명단 비공개 |
| 6 | 방산업체 망분리 | 현재 조건으로만 사용, 선택 항목 | 명단은 공개되나 완화 계획 없음. 방향성 근거로 부적합 |
| 7 | 이미 시행 중인 규제 | 방향성 근거로 미사용 | 현재 상태 구성 자료로만 사용 |
| 8 | CBAM 1차 적용 대상만 분석 | 2차 적용 예정 대상(2028 확대안) 추가 | 1차 적용 대상만으로는 대상이 수십 곳 수준으로 한정됨 |
| 9 | IBM Data & AI 제품군 전체로 확장 | 데이터 층 역할로 한정 | Envizi는 Automation 소속 추정으로 분석 대상 밖 |

## 8. 분석 구조 (설계 시점 기준)

1. **비용**
   - 진입 경로 3개: A 온라인 버전 / B 신규 설치 / C 기존 OpenShift 위 추가
   - 비공개 단가는 변수로 처리
   - 3단계에서 D(BYOC) 추가
2. **부담 수준**
   - 설계 시점: 매출 × IT 지출 비율(2%·3.5%·5%)로 IT 예산 추정
   - 3단계에서 한국인터넷진흥원 정보보호 공시의 정보기술부문 투자액(실측값)으로 교체
3. **조건**
   - 현재: OpenShift 보유 여부(시나리오), 방산 망분리(선택)
   - 향후: CBAM 1차 적용(배출권 명단 + 공시 언급), 2차 적용 예정(확대안 업종), 배터리 여권(보조)
   - 2단계에서 배터리 여권은 공시 언급 2곳에 그쳐 본문 근거에서 제외

## 9. 한계 (최종 문서에 명시)

- 2차 적용 예정 품목은 EU 최종 협상 중임
- 기본값·할증은 2027년 말까지 변경 가능함
- 법적 신고 의무는 EU 수입업자에게 있음. 국내 제조기업은 데이터 제공자임
- 데이터 층이 1·2차 적용 단계를 연결하는 경로가 된다는 판단은 가설임
- 라이선스·서버 단가 비공개로 결과는 범위 또는 기준선으로 제시함
- 서울 리전 부재는 공개 자료 기준임
- 기업별 OpenShift·소프트웨어 현황, EU 수출 여부 비공개임
- 중견 판정은 상장사 한정, 계열사 매출 합산 미반영
- Envizi 소속은 추론임
- 계산 결과가 가설과 반대일 경우 그대로 보고함
