## 6. 대기업 처리
- 대기업 111곳은 분석 대상에서 제외하지 않고 비교 기준으로 유지
- 판정·적용 단계 분류는 중견 기업과 동일하게 완료
- 중견 기업 중심 분석 근거
  - 계산 결과가 기업별로 달라질 가능성이 높은 구간이 중견 기업임 (중소기업은 예산 단위 불일치, 대기업은 규모상 선택지가 넓을 것으로 가정)
  - 기존 조사(대한상의 등)가 대기업·중소기업만 구분하여 중견 기업 데이터 공백이 큼
- "대기업은 선택지가 넓다"는 가정은 3단계에서 IT 예산 증가율로 검증함 (대기업 0.2~0.8%로 확인)

## 9. 주요 발견
- 1차 적용 대상 중견 기업 58곳 중 2025년 사업보고서에 CBAM을 언급한 기업 5곳, 데이터·시스템 대응(LCA 시스템 구축)을 기재한 기업 1곳
- 공시 기준 CBAM 인식·대응 기재 수준은 낮음 (미기재가 대응 미비를 의미하지는 않음)
- 2차 적용 예정 대상을 포함하면 대응 필요 중견 기업이 1차 적용 대상 대비 최소 1.6배로 증가

## 10. 정정 기록

| 최초 판단 | 정정 내용 |

## 11. 한계
- 전자공시 업종코드가 3자리로 등록된 기업이 많아 세부 품목 구분 불가 → 후보로 분류
- 특수 목적용 기계(292) 후보에 반도체·디스플레이 장비 제조기업이 포함될 수 있어 최대값 과대 가능성 있음
- 제품명 판정은 기업별 첫 문맥 1개 기준. 핸즈코퍼레이션은 추가 확인 필요
- 사업보고서 미기재가 CBAM 대응 미비를 의미하지는 않음
- 기업별 EU 수출 여부 미확인 (유럽 언급 횟수는 수집했으나 판단 근거로 미사용)
- 2차 적용 예정 품목은 EU 최종 협상 중으로 변경 가능
- "해당/후보" 구분에 판단 개입 (전동기·변압기, 전선·케이블은 대표 제품으로 보아 해당 처리)
- 배출권 대조 중 (주)케이씨는 동명 이업체일 가능성 있음
- 더네이쳐홀딩스는 지주회사가 아닌 운영회사일 가능성 있음 (1차 적용 대상과 무관)
- 중소기업 판정 시 관계기업 합산, 자산 5,000억 원 이상 법인의 30% 이상 소유 기준 미반영
- 공정위 파일로 번호를 직접 대조하지 못한 업종(2915, 2923, 25943, 25944)은 상장 제조기업이 없어 결과 영향 없음
